# Real Shack-Hartmann spot data proves scarce

No public dataset currently satisfies the full spec of a **16×16-lenslet, 256×256-detector-class** Shack-Hartmann (SH) reconstruction pipeline validated on real, physically-recorded raw spot images with independent calibration metadata — and all three named leads fail on inspection. The Ramirez-Quintero 2025 *Scientific Reports* dataset is real but **request-only**, with ground truth that is SLM-commanded rather than independently measured ([PMC11926174](https://pmc.ncbi.nlm.nih.gov/articles/PMC11926174/)). The Durham "PPPPP" collection is real and publicly licensed (CC BY-SA 4.0) but its Shack-Hartmann content has already been reduced to **slopes**, not raw lenslet spot images — the raw camera frames in that collection belong to a different, lenslet-free sensor (PPPP) ([researchdata.durham.ac.uk](https://researchdata.durham.ac.uk/files/r2np193923h)). Zenodo 14964320 is definitively refuted: its 25-file manifest contains zero image files of any format ([zenodo.org/api/records/14964320](https://zenodo.org/api/records/14964320)). Broadening the search across astronomical AO testbeds, ophthalmic aberrometers, and general open-data repositories turned up only one directly-verified real-instrument raw-frame release — a three-image demo folder from the Roorda Lab's ophthalmic wavefront sensor on GitHub — plus several partially-promising but unverified leads (ESO's SPHERE archive, a DIY teaching-lab GitHub repo, and the MAVIS DNU laboratory bench). The practical conclusion for a hardware-verification journal paper is that public raw SH imagery essentially does not exist at the needed scale and documentation level; the path forward runs through **direct author requests** to the two best-positioned groups, not further search.

## Two of three named leads collapse, one is gated behind a request

The Ramirez-Quintero et al. 2025 paper (DOI 10.1038/s41598-024-80615-8) is the most physically credible of the three named leads: a real monocular visual simulator built at the University of Antioquia, using a genuine Hartmann-Shack sensor (**1280×1024 px CMOS, 5.3 μm pixels**, Flexible OKO Optical lenslet array with **300 μm pitch and 3.2 mm focal length**) and a real Holoeye PLUTO-NIR spatial light modulator (1920×1080 px, 8 μm pitch) to project commanded Zernike aberration phase maps ([PMC11926174](https://pmc.ncbi.nlm.nih.gov/articles/PMC11926174/); [Holoeye reference page](https://holoeye.com/papers-references/experimental-wavefront-sensing-techniques-based-on-deep-learning-models-using-a-hartmann-shack-sensor-for-visual-optics-applications/)). But the paper's Data Availability statement, read directly from the PMC full-text mirror, restricts access to **"upon reasonable request"** — there is no Figshare, Zenodo, GitHub, or Supplementary Information download link ([PMC11926174](https://pmc.ncbi.nlm.nih.gov/articles/PMC11926174/)). Critically, the aberration "ground truth" for this dataset is the **SLM's commanded phase-map setpoint**, not an interferometric or otherwise independent measurement of the wavefront actually delivered to the sensor — so any reconstruction-accuracy claim built on this data would really be accuracy-against-setpoint, blind to SLM phase nonlinearity and residual relay-optics aberration. Camera bit depth, exact preprocessing/crop pipeline to a fixed neural-network input size, and whether dark/flat/lenslet-map calibration files exist were all absent from the extractable text.

The Durham "PPPPP" collection (`collections.durham.ac.uk/r2gb19f5844`) turns out to be a case of a misleading title. Its own name — **"PPPP beam profiles and measured Shack Hartmann slopes from the PPPPP experiment"** — draws exactly the distinction that matters: the raw camera images deposited are from the **PPPP (Projected Pupil-Plane Pattern) sensor**, a lenslet-free pupil-imaging WFS technique, while the Shack-Hartmann sensor's contribution has already been reduced to **slopes** before deposit ([search-index snippet via collections.durham.ac.uk](https://collections.durham.ac.uk/collections/r2gb19f5844?page=2)). A directly-fetched sibling README record confirms the dataset is real (DARC real-time-controller-driven cameras and an ALPAO-class deformable mirror on a genuine AO lab bench), CC BY-SA 4.0 licensed, deposited by **Nazim Bharmal** at Durham, funded by STFC ([researchdata.durham.ac.uk/files/r2np193923h](https://researchdata.durham.ac.uk/files/r2np193923h)). The associated peer-reviewed paper (*International Journal of Optomechatronics* 18(1), 2024, DOI 10.1080/15599612.2024.2386985) confirms the same repository DOI is the paper's official data-availability link ([tandfonline.com abstract](https://www.tandfonline.com/doi/abs/10.1080/15599612.2024.2386985)). So this is a genuine, openly-licensed, physically-recorded dataset — just not a Shack-Hartmann raw-spot-image dataset as defined by the task. Whether the underlying SH raw camera frames (pre-slope-reduction) still exist and were simply not deposited is unconfirmed and would need to be asked of Bharmal directly.

Zenodo 14964320 ("Codebase for Wavefront Aberration Calibration Using Supervised and Deep Learning (SHWFS)," Mario Alberto Jara, CC BY 4.0) is the cleanest refutation of the three. A full file-manifest fetch via the Zenodo REST API lists all 25 files: Jupyter notebooks, Python scripts, CSV/XLSX statistics summaries, and large binary `.dat` arrays named `Z_train.dat` (777.7 MB), `Z_test.dat` (129.6 MB), `W_train.dat` (24.5 MB), and smaller variants — with **zero files in any image format** (no .png/.tif/.fits/.raw) anywhere in the record ([zenodo.org/api/records/14964320](https://zenodo.org/api/records/14964320)). The naming convention and the record's own framing as a calibration/ML "codebase" strongly suggest these `.dat` arrays are Zernike-coefficient or wavefront-vector training tensors rather than imagery, and the companion SPIE Optical Engineering paper (Jara Reyna et al. 2025) could not be opened to confirm whether the underlying training data originated from simulation or from a real bench — but regardless of that provenance question, no raw camera images exist in this record at all.

## Astronomical AO testbeds guard their raw frames behind institutional walls

The survey of astronomical and laboratory adaptive-optics testbeds found real hardware everywhere but almost no public raw-frame downloads. ESO's Science Archive Facility hosts all raw VLT data since October 2014 and has a dedicated query form for SPHERE, whose SAXO wavefront sensor is a genuine **40×40-lenslet Shack-Hartmann array with a sub-electron-noise EMCCD** operating on-sky since 2014 ([ESO SPHERE archive form](http://archive.eso.org/wdb/wdb/eso/sphere/form)). This is credible on scale and documentation grounds, but whether the public query interface exposes the *internal AO-loop WFS pixel frames* — as opposed to science-camera exposures — was not directly confirmed; that requires a live, hands-on query against the archive rather than a metadata read, and is the single highest-value verification step left undone in this research pass. The Zenodo record for "Laboratory tests of the MAVIS DNU Shack Hartmann Wavefront Sensor" describes an even more attractive ground-truth setup — a real bench at the University of Padova pairing an **ALPAO 97-15 deformable mirror with a 4D Phasecam 4030 interferometer**, giving simultaneous commanded-and-independently-measured aberration ground truth, which is exactly the kind of provenance a hardware-verification paper would want — but the record itself is a single 6.9 MB conference-proceedings PDF, not a data deposit; no pixel files are attached ([Zenodo 21107489](https://zenodo.org/records/21107489)). CANARY (William Herschel Telescope), HeNOS (University of Victoria), PAPYRUS (OHP, which in any case runs a Zernike/pyramid sensor rather than a lenslet SH), and SEAL (UC Santa Cruz) all have documented SH-relevant hardware in the literature but no discoverable public data repository ([arXiv 1610.06313](https://arxiv.org/pdf/1610.06313)). The pattern across this entire track is consistent: AO groups either keep raw WFS pixels behind institutional access or reduce them to slopes/Zernike coefficients before any public release, and none of the GitHub tool repositories found (`ShackHartmannAnalysis`, `mshwfs`, `SH-CNN`) could be confirmed to ship real (as opposed to simulated or unlabeled-provenance) sample frames.

## Ophthalmic aberrometry yields exactly one small, real, undocumented sample

Vision-science and ophthalmic Shack-Hartmann aberrometers are widely used clinically, yet the search surfaced only a single directly-verified public release of real raw spot images: the GitHub repository `kaccie14/shwfs`, which bundles three raw TIFF frames (`R25M0004g.tif`, `R25M0005g.tif`, `R25M0006g.tif`) plus a `background.tif` reference frame, with a README stating plainly, **"All images are from Roordalab's custom-built WFS"** — a real instrument built in Austin Roorda's adaptive-optics ophthalmoscopy lab at UC Berkeley ([github.com/kaccie14/shwfs](https://github.com/kaccie14/shwfs)). This is the strongest real-instrument candidate found across the entire ophthalmic track precisely because it is the only one that is neither simulated nor request-gated — it is already sitting in a public, unauthenticated repository. But it is a bare-bones engineering demo, not a curated dataset: no sensor geometry (resolution, bit depth, lenslet pitch, focal length) is stated anywhere in the retrievable README; no license file exists in the repo, so reuse terms are unstated; no ground-truth aberration values accompany the frames; and it is unresolved whether the subject was a human eye, a model eye, or a bench test target. Every other ophthalmic candidate failed harder: the PMC11086325 deep-learning ocular-SH paper explicitly generates its "Hartmannograms" via Fourier-optics simulation from statistical eye models (20×20 lenslets, 300 μm pitch, 6.5217 μm pixel pitch, downsampled to 200×200/224×224 from 920×920 — useful only as a geometry reference point, not real data) ([PMC11086325](https://pmc.ncbi.nlm.nih.gov/articles/PMC11086325/)); a Biomedical Optics Express multi-layer SH paper (Akondi & Dubra) is request-only ([BOE 12(1):409](https://opg.optica.org/boe/abstract.cfm?uri=boe-12-1-409)); and a Zenodo "virtual multi-eccentric Hartmann-Shack aberrometer" dataset (DOI 10.5281/zenodo.21227985) is explicitly synthetic MATLAB-generated data ([Sensors 26(14):4419](https://doi.org/10.3390/s26144419)).

## Other domains add two long shots, neither confirmed

Searches outside astronomy and ophthalmology — laser/beam metrology, X-ray synchrotron metrology, fracture mechanics, and DIY/educational SH builds — surfaced no clean hit but two candidates worth tracking. A DMD-based "Wavefront Sensor for Laser Beams" (Zenodo 18696645/18692566, CC BY 4.0) is real bench work validated against a commercial shearing interferometer, but it uses a **digital micromirror device, not a lenslet array**, disqualifying it on sensor architecture even though its 57.6 MB `Dataset.zip` companion record was never opened to confirm file-level contents ([Zenodo 18696645](https://zenodo.org/records/18696645); [Zenodo 18692566](https://zenodo.org/records/18692566)). More interesting is `congzhou235-prog/iccp-adaptive-optics-2026`, an ICCP 2026 mini-course from a computational-imaging lab that documents building a real SH sensor (parts list, CAD/STEP files) and ships a `dataset/` folder organized into `first_10_zernike/`, `last_10_zernike/`, and `mixed_zernike/` subfolders alongside a `manifest.csv` and a `calibration_pics/` directory ([github.com/congzhou235-prog/iccp-adaptive-optics-2026](https://github.com/congzhou235-prog/iccp-adaptive-optics-2026)). The hardware is unambiguously real, but whether the shipped images are actual captures from that hardware or rendered/simulated training examples generated to match the Zernike-mode folder labels was never resolved — the `manifest.csv` was never opened to check. A hard X-ray synchrotron SH metrology paper (KIT, using 2D refractive lens arrays as the lenslet equivalent) is a genuine non-astronomy, non-ophthalmic conventional-SH application but has no associated public data repository ([PMC7206553](https://pmc.ncbi.nlm.nih.gov/articles/PMC7206553/)).

## Ranked shortlist and what the top candidates still need

Weighing hardware fidelity, documentation completeness, and access path, the five most promising candidates for a 16×16-lenslet, 256×256-detector-class validation dataset rank as follows.

| Rank | Candidate | Access path | Why it ranks here |
|---|---|---|---|
| 1 | Ramirez-Quintero et al. 2025 (Sci Rep) | Author request | Only candidate with a fully-documented, matched lenslet/camera/SLM optical chain on a real bench; ground truth is commanded (not interferometric), and the data itself must be requested |
| 2 | `kaccie14/shwfs` (Roorda Lab, GitHub) | Already public | Only real-instrument SH imagery that requires no request at all, but tiny (3 frames), undocumented geometry, no license, no ground truth |
| 3 | ESO SPHERE/SAXO archive | Public archive query | Largest-scale real 40×40-lenslet SH sensor with an institutional raw-data policy, but WFS-pixel-frame exposure through the public form is unverified and needs a live query, not an author email |
| 4 | Durham "PPPPP" collection | Already public (CC BY-SA 4.0) | Real, openly-licensed AO bench data, but the SH content is slopes-only; raw SH frames (if they exist) would need to be requested from the depositor |
| 5 | `congzhou235-prog/iccp-adaptive-optics-2026` | Already public (GitHub) | Real, documented hardware build with a labeled Zernike-mode dataset structure, but real-vs-simulated provenance of the images themselves is unverified |

For the top two, here is precisely what would need to be requested from the authors, without drafting or sending anything:

**Ramirez-Quintero et al. 2025 (University of Antioquia, Optics and Photonics group).** Request: (1) the raw camera frames themselves for both the Noise-Free Images (NFI) and Artificial-Eye Images (AEI) datasets, ideally uncropped at native 1280×1024 resolution rather than only the network-preprocessed crops; (2) the corresponding SLM Zernike-coefficient setpoint file for every frame (the commanded ground truth); (3) camera bit depth, which is absent from the published text; (4) the exact preprocessing pipeline (crop/resize/normalization) used to reach the paper's neural-network input size, since the paper's own stated input resolution could not be recovered from the extractable text and needs to be confirmed as matching or convertible to a 256×256-class geometry; (5) any dark, flat, or background reference frames and a lenslet-registration map or pupil mask, none of which are mentioned in the Methods text; (6) confirmation of whether repeated exposures were captured per aberration setting (needed to separate sensor noise from model error); and (7) explicit reuse/license terms for the data itself, since the article's Open Access status covers the text and figures, not necessarily the underlying images.

**`kaccie14/shwfs` (Roorda Lab, UC Berkeley — repository maintained by GitHub user `kaccie14`).** Request: (1) full sensor geometry — lenslet pitch, lenslet focal length, camera pixel size/pitch, native resolution, and bit depth, none of which appear in the repository's README; (2) subject identification for each of the three sample frames (human eye vs. model/artificial eye vs. bench test target), which determines whether the data is usable as an ophthalmic validation case or only as a generic optical-bench sanity check; (3) clarification of whether `background.tif` is a true dark frame (no illumination) or a flat/reference frame (illuminated, no spots), since the filename alone is ambiguous; (4) any available aberration ground truth (Zernike coefficients or equivalent) for the three frames, since none currently accompanies them; (5) explicit license/reuse permission, since no LICENSE file exists in the repository; and (6) ideally, an expanded set of frames spanning multiple distinct aberration states rather than the three demo images currently present, which read as a data-reduction-pipeline demo rather than a validation corpus.

## Conclusion

The clearest takeaway is structural, not incidental: the Shack-Hartmann research community — across astronomy, ophthalmology, and every adjacent metrology domain searched — treats raw lenslet-spot camera frames as a disposable intermediate product. Papers publish reconstructed wavefronts, Zernike coefficients, or slopes; the pixel data that produced them is either never retained for release, reduced before deposit (as at Durham), or held back under "available upon reasonable request" boilerplate (as at Antioquia) that in practice functions as a soft embargo. This means a hardware-verification journal paper built on truly public raw SH imagery is not currently achievable through search alone — the only unconditionally public real-instrument sample (`kaccie14/shwfs`) is too small and undocumented to carry a validation claim by itself. The practical implication is that author outreach to Ramirez-Quintero's group and to the Roorda Lab, run in parallel with a live (not metadata-only) query of ESO's SPHERE archive for SAXO WFS pixel products, is the fastest realistic route to a defensible dataset — and even a successful request will likely need to be supplemented with an in-house optical-bench capture, since none of the five shortlisted candidates independently supplies both full calibration metadata and interferometrically-verified (rather than commanded) ground truth at the 16×16/256×256 scale the pipeline targets.
